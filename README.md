# Retail Sales Dashboard – Walmart

## 📊 Project Overview

An interactive retail sales dashboard created using Microsoft Excel to analyze Walmart sales data and present key business metrics and trends through visualizations.

## 🎯 Project Objective

The objective of this project is to analyze retail sales data, identify important sales trends, and present the findings through an interactive Excel dashboard.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Data Visualization
* Dashboard Creation

## 📈 Dashboard

The dashboard provides a visual representation of retail sales performance and helps users understand important business trends from the underlying sales data.

## 🔍 Analysis

The project includes analysis of retail sales data using Excel-based data processing, pivot tables, charts, and dashboard visualizations.

## 📁 Files Included

* `Retail-Sales-Dashboard.xlsx` – Excel workbook containing the retail sales analysis and dashboard.

## 💡 Key Skills Demonstrated

* Data cleaning and preparation
* Exploratory data analysis
* Excel-based reporting
* Pivot table analysis
* Data visualization
* Dashboard development
